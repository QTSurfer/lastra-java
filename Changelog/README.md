# Changelog

Record of notable changes to this repository.
Each logical change is recorded in a Markdown file inside the directory for its month.

## Conventions

- Directory: `YYYY-MM/`.
- File name: `YYYY-MM-DDTHH-MM_short-slug.md` (UTC, 24-hour clock). The `YYYY-MM` prefix
  is retained in the filename so entries remain identifiable when copied or referenced
  outside this directory.
- List months with `ls -1`; list entries within a month with `ls -1 Changelog/YYYY-MM/`.
- Add a new month directory when the first entry for that month is created.
- Every entry should explain what changed, why it changed, and how it was carried out.
  Add validation and cross-references when they apply.
- For multi-repository changes: create one entry per repository, each from that repository's
  perspective, cross-linked under Refs.
- Prefer a new entry over editing an existing one — the Changelog is append-only.
